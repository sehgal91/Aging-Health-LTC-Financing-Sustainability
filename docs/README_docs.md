# Supplementary documentation

The final author-approved Supplementary Materials are archived here as `Supplementary_Materials.pdf`.

Machine-readable summaries of key reported results are provided in `outputs/tables/`, including the final SHAP importance results, sequential conformal prediction results, robustness summaries, and scenario-sensitivity documentation.

The Supplementary Materials and repository outputs should be interpreted together with the scope and evidence boundaries described in `README.md` and `REPRODUCIBILITY.md`.
