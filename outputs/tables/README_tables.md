# Reported tables

The CSV files in this directory are archival reported outputs. Headline predictive results are separated into validation selection and a single untouched 2022–2023 test evaluation. SHAP values are model-description summaries, not causal effects. Sequential conformal results report empirical sample calibration. Scenario outputs cover 2024–2028 and are sensitivity trajectories, not forecasts.

Files containing obsolete 2050 scenarios or superseded test-set claims have been removed rather than silently relabeled.
